# Contributing

Use fictional or redistributable examples in issues, screenshots and tests.
Do not attach private peer reviews, unpublished manuscripts, credentials or
local database files.

Run the checks in `docs/testing.md` before proposing changes. Keep optimistic
revision checks, atomic persistence and source hashes intact. Make migrations
explicit if you change stored document or annotation schemas. Application UI
text currently defaults to Chinese; English documentation and bilingual content
are included. Additional UI translations are welcome.
